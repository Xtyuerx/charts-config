# MessagePack 牙齿分割边界编辑

入口：`/msgpackTeeth`。使用 Vue 3、TypeScript、Three.js 和 `@msgpack/msgpack`。

## 使用

1. 加载本地 `.msgpack` / `.bin`，或包含双位十六进制字节的 `.hex` / `.txt`（支持空白分隔和开头 `0x`）。也可以加载 URL。
2. 自动优先使用 `lower_seg` / `upper_seg` 的网格和顶点 `seg_labels`。自定义结构可查看字段结构，填写网格和标签路径，再点“应用字段路径”。支持 `drcp`、`dcrp`、`drc` 包装的 Draco 数据。
3. Ctrl 点击牙齿切换选中边界。蓝色控制点在选中后变白，边界线保持绿色。拖动控制点时闭合 Catmull-Rom 曲线重新拟合并约束到三角网格表面。
   边界线与控制点使用模型深度进行遮挡，背面不会穿透显示，也无法隔着模型拾取。旋转视角没有惯性。
4. 松手提交局部标签；取消指针操作回退本次拖动。超出编辑范围或无法可靠分区时拒绝提交并恢复曲线。
5. “重置选中边界”恢复该牙的初始曲线及编辑标签。上下颌切换保留各自的编辑历史和原始编辑范围。
6. “保存完整 msgpack”或“保存完整 hex”下载完整数据包。导出包含全部原字段、上下颌和当前标签；没有增量导出或自动上传。

## 数据和算法约束

- 原始 Draco 解码网格保留顶点索引。显示用分区网格是独立派生数据，不作为标签索引来源。
- 牙龈与牙齿采用不同的显示深度偏移，避免几乎重合的表面交替露色形成细虚线；加载与编辑后更新统一使用相同材质设置。仅影响显示，不改变网格位置或导出数据。
- 在标签不一致的三角面中，以跨标签边中点连接边界；三标签交汇面通过面重心连接。每颗牙选择最长的有效闭合轮廓；开放或非流形轮廓不会猜测闭合。
- 闭合轮廓等弧长采样最多 20 个控制点。拟合曲线采样后，经已有表面路径工具穿过三角面，显示和标签分区使用同一条路径。
- 原边界周围 4 圈相邻三角面组成固定编辑带。只有带内原始顶点可改标签；切换颌位不会扩大编辑带。
- 松手后，曲线阻断三角面间的连通关系，原牙内种子决定牙齿侧。原外侧种子必须属于另一侧，且可靠的编辑带外背景面不能落入牙齿侧。面分区通过顶点相邻面的多数投票量化回顶点；平票保留当前归属。
- 脱离目标牙区域的顶点恢复为沿网格邻接关系找到的原外侧标签。共享顶点按牙号保存编辑栈，重置任一牙不会丢失其他牙的编辑层。
- 回写当前字段路径的 `seg_labels`，并新增 `boundary_editor` 字段保存编辑控制点。不重新编码 Draco，不改 `mesh.data`、网格拓扑、`align_matrix`、`label_curvature`、`adj_tooth_ids` 或已有单牙数据。这些派生字段不会自动重新计算。
- 只有面标签或独立单牙数据时，可保存并恢复边界点位和颜色预览，但不会生成原始顶点标签。
- 预览模式将边界采样点投影到目标牙齿及牙龈表面，再沿连续三角面构造路径。显示线与颜色分区直接共享这条路径；无法连续贴合的模型间隙会拒绝本次拖动。保存与恢复使用网格缓冲区相同的浮点精度。
- 颜色预览沿实际路径切分显示用三角面，并在切分后的表面单元上计算连通分量。边界外的原牙色会被移除，边界内连通牙龈表面以所属牙色覆盖；不再使用全局二维投影多边形或局部新旧轮廓差集。原始网格、法线缓冲区及导出载荷不因此重写，新增显示顶点使用原面法线的重心插值。
- 整颌预览共用一份不可变参考表面，投影查询复用 BVH。颜色覆盖层随所属牙齿显隐。自交、无法分隔内外或跨入其他牙齿的编辑会被拒绝；校验完成前不发布控制点、显示线或颜色。重新加载使用保存的原始轮廓确定内侧方向，避免缩小边界后按剩余面积反转颜色。加载候选模型的颜色校验在替换当前模型之前完成。
- 导入时记录原始轮廓中已经存在的跨牙重叠区域，保留其他牙齿的原始显示；后续编辑只拒绝新增的跨牙面积，按同一原始三角面内的凸多边形交叠面积判定，不能仅按面编号放行。零面积三角面从显示参考和控制点投影 BVH 中同时排除，原始缓冲区不变。
- `boundary_editor.version = 1`；`scopes` 按颌位及字段路径隔离，每颗牙保存编辑模式、原边界点和控制点。重新打开优先恢复控制点，避免小幅拖动未改变标签或标签量化后丢失精确曲线。已有文件缺少该字段时仍自动提取边界。重置删除该牙的编辑记录；空的元数据字段会移除。
- 本页面能够识别 `boundary_editor`。其他渲染系统需读取修改后的 `seg_labels` 或支持此编辑字段；读取已有单牙网格不会得到新分割形状。

## 验证

页面范围类型检查：

```powershell
node node_modules/vue-tsc/bin/vue-tsc.js -p tsconfig.msgpack-check.json --pretty false
```

启动开发服务后执行相关回归测试（默认服务地址 `http://127.0.0.1:4175`；页面测试也接受 `MSGPACK_TEST_URL`）：

```powershell
node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 4175
node node_modules/@playwright/test/cli.js test tests/msgpackBoundary.spec.ts tests/msgpackBoundaryRendering.spec.ts tests/msgpackRegionColors.spec.ts tests/msgpackSegmentation.spec.ts tests/msgpackTeeth.spec.ts tests/msgpackTeethPage.spec.ts tests/msgpackEditingPage.spec.ts --project=chromium --workers=2
```

测试包含真实 Draco 编解码、hex 上传、鼠标拖动、局部标签 diff、完整二进制/hex 下载、上下颌状态保留、精确重置、取消拖动、失败候选文件手动恢复以及方向反转拒绝。新增 `msgpackSurfacePartition.spec.ts` 和 `msgpackSurfaceColors.spec.ts` 覆盖三角面内精确切分、折叠表面、邻近不连通表面、边界外残色清理、牙龈扩展归属、资源恢复及缩小后重载；页面测试覆盖无效保存边界不能替换当前模型。

`msgpackRealLoad.spec.ts` 接受 `MSGPACK_LOAD_SAMPLE` 本地文件路径和 `MSGPACK_TEST_URL` 开发服务地址，验证真实文件上传、上下颌来回切换和完整下载内容不变。2026-10-26 使用用户提供的本地文件验证：下颌 15 个分区 / 154907 个三角面，上颌 16 个分区 / 154875 个三角面，切换返回下颌及原内容导出均通过。样本未复制到仓库中。
